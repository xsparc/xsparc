# Louijie Compo

Systems & AI engineer building software for devices, simulations and AI tools. I make engineering claims inspectable through public code, retained results and explicit limits.

[Start here](https://louijiecompo.com/start-here/) · [Portfolio](https://louijiecompo.com) · [Writing](https://louijiecompo.com/writing/) · [Hugging Face model archive](https://huggingface.co/louijiec)

## Current highlights

- **[AeroLoop](https://github.com/xsparc/aeroloop)**: follow recorded drone-control experiments and inspect flight and landing behavior. Simulation only; failed acceptance gates remain visible. [Explore the recorded results](https://louijiecompo.com/work/aeroloop/).
- **[Cogniform](https://github.com/xsparc/cogniform)**: let software change a 3D scene, then inspect images and object data tied to the same scene version. Early Rust engine; diagnostic images accompany canonical observations. [Inspect the captured example](https://louijiecompo.com/work/cogniform/).
- **[Omniweft](https://github.com/xsparc/omniweft)**: build and change a small world through a Python SDK, with explicit permissions and recoverable edits. Experimental C++20 engine with Vulkan presentation. [Explore the room showcase](https://louijiecompo.com/work/omniweft/).

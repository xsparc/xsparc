# Louijie Compo

Systems & AI engineer building simulation, embedded, agentic and applied-intelligence systems. I make engineering claims inspectable through public code, retained results and explicit limits.

[Portfolio](https://louijiecompo.com) · [Writing](https://louijiecompo.com/writing/) · [Hugging Face model archive](https://huggingface.co/louijiec)

## Current highlights

- **[AeroLoop](https://github.com/xsparc/aeroloop)**: simulation-only drone control experiments, recorded flight inspection and landing-contact diagnosis. Experimental improvements retain failed acceptance gates. [Case study](https://louijiecompo.com/work/aeroloop/)
- **[Cogniform](https://github.com/xsparc/cogniform)**: agent-operable 3D scenes with canonical observations and optional bounded diagnostic PNGs over MCP. Exact values and causal identity stay in the canonical resource. [Case study](https://louijiecompo.com/work/cogniform/)
- **[Omniweft](https://github.com/xsparc/omniweft)**: explicit world authority, bounded worker recovery and geometry import with provenance. Imported scenes remain detached until separately authorized integration. [Case study](https://louijiecompo.com/work/omniweft/)
